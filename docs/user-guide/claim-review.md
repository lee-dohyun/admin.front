# 고객 취소·반품 신청 처리하기 사용 설명서

| 항목 | 내용 |
|---|---|
| 대상 | 직원(주문 관리) |
| 화면 주소 | <https://admin.posselect.com/admin/orders/claims> |
| 필요한 권한 | 「주문 관리」 역할(ORDER_MANAGER) 또는 시스템 관리자(SYSTEM_ADMIN) |
| 최종 확인 | (미확인) — 2026-10-14 자동 테스트(승인 본문·반려 사유 검사)만 통과. 배포 전이라 실제 화면으로는 아직 확인하지 못했다 |
| 관련 이슈 | lee-dohyun/gateway#320 |

## 1. 이 기능으로 할 수 있는 일
고객이 마이페이지에서 신청한 반품을 확인하고 승인(환불)하거나 반려한다. 처리된 취소·반품의 환불 내역도 본다.

## 2. 시작하기 전에
- 출고 전 취소는 고객이 신청하는 즉시 환불까지 끝난다. 이 화면의 「처리 대기」에는 반품만 올라온다.
- 승인하면 바로 환불되고 그 상품의 재고가 돌아온다. 되돌릴 수 없으니 회수품을 확인한 뒤 승인한다.

## 3. 따라 하기
### 3-1. 반품 승인하기
1. 「주문 관리」 → 「취소·반품 신청 보기」(또는 메뉴 「취소·반품 신청」)를 연다. 「처리 대기」 탭이 열려 있다.
2. 신청의 상품·사유·상세 사유를 확인한다.
3. 필요하면 「승인 사유」를 바꾼다(예: 고객은 「단순 변심」을 골랐지만 회수품이 파손돼 있으면 「상품 불량·파손」).
4. 「승인(환불)」 → 「신청 #N을(를) 승인할까요? 바로 환불됩니다.」에서 확인을 누른다.
5. 목록에서 사라지면 끝이다. 「완료」 탭에서 환불 금액과 내역(상품·할인 몫·배송비·반품 배송비)을 볼 수 있다.

### 3-2. 반품 반려하기
1. 「반려 사유(고객에게 보임)」에 사유를 적는다. 고객의 주문 상세에 「반려 사유: …」로 그대로 보인다.
2. 「반려」를 누른다. 고객은 같은 상품을 다시 신청할 수 있다.

## 4. 입력 항목 설명
| 항목 | 필수 | 형식·제한 | 예 |
|---|---|---|---|
| 승인 사유 | 아니요(기본은 고객이 고른 사유) | 단순 변심 / 상품 불량·파손 / 오배송 | 상품 불량·파손 |
| 반려 사유 | 반려할 때 필수 | 1~300자, 고객에게 그대로 보임 | 사용 흔적이 있어 반품할 수 없습니다 |

## 5. 상태와 진행 흐름
| 상태(탭) | 뜻 | 다음에 할 일 / 누가 |
|---|---|---|
| 「처리 대기」 | 고객이 반품을 신청했다 | 직원이 승인 또는 반려 |
| 「완료」 | 환불이 끝났다(취소는 고객 신청 즉시, 반품은 승인 즉시) | 없음 |
| 「반려」 | 직원이 반품을 받아들이지 않았다 | 고객이 다시 신청할 수 있다 |

## 6. 자주 보는 메시지와 해결 방법
| 화면 메시지(원문) | 원인 | 해결 |
|---|---|---|
| 「반려 사유를 입력하세요. 고객 화면에 그대로 보입니다.」 | 반려 사유가 비어 있다 | 사유를 적는다 |
| 「반려 사유는 300자 이내로 입력하세요.」 | 사유가 너무 길다 | 줄인다 |
| 「이미 처리된 신청입니다.」 | 다른 직원이 먼저 처리했다 | 탭을 다시 눌러 목록을 새로 고친다 |
| 「신청 목록을 불러오지 못했습니다.」 | 주문 서비스에 일시적으로 닿지 못했다 | 잠시 뒤 다시 연다 |

## 7. 알아 둘 제한 사항
- 환불 금액은 주문 서비스가 계산한다: 상품 금액 − 회원 등급 할인 몫 ± 배송비 재계산(단순 변심일 때) − 반품 배송비(단순 변심일 때). 사유를 「상품 불량·파손」「오배송」으로 바꾸면 반품 배송비와 배송비 차감이 빠진다.
- 반품 배송비는 상품 판매 정책의 「반품 배송비(편도)」다. 입력되지 않은 상품은 0원이다.
- 결제는 아직 실제 PG 가 아니다. 「환불」은 주문 서비스의 기록이고 실제 돈이 오가지 않는다.
- 교환은 아직 없다.

## 8. 문의
화면 오류는 개발 담당에게 신청 번호(#N)와 함께 알린다.
