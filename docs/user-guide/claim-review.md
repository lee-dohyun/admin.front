## 1. 이 기능으로 할 수 있는 일
고객이 마이페이지에서 신청한 반품·교환을 확인하고 승인하거나 반려한다. 교환은 승인 뒤 새 상품을 보내고 운송장을 등록하면 끝난다. 처리된 취소·반품의 환불 내역도 본다.

## 2. 시작하기 전에
- 출고 전 취소는 고객이 신청하는 즉시 환불까지 끝난다. 이 화면의 「처리 대기」에는 반품과 교환만 올라온다.
- 교환은 상품 불량·파손이나 오배송일 때, 같은 상품의 같은 가격 옵션으로만 신청된다(단순 변심 교환은 받지 않는다).
- 승인하면 바로 환불되고 그 상품의 재고가 돌아온다. 되돌릴 수 없으니 회수품을 확인한 뒤 승인한다.

## 3. 따라 하기
### 3-1. 반품 승인하기
1. 「주문 관리」 → 「취소·반품 신청 보기」(또는 메뉴 「취소·반품 신청」)를 연다. 「처리 대기」 탭이 열려 있다.
2. 신청의 상품·사유·상세 사유를 확인한다.
3. 필요하면 「승인 사유」를 바꾼다(예: 고객은 「단순 변심」을 골랐지만 회수품이 파손돼 있으면 「상품 불량·파손」).
4. 「승인(환불)」 → 「신청 #N을(를) 승인할까요? 바로 환불됩니다.」에서 확인을 누른다.
5. 목록에서 사라지면 끝이다. 「완료」 탭에서 환불 금액과 내역(상품·할인 몫·배송비·반품 배송비)을 볼 수 있다.

### 3-2. 반품 반려하기
1. 「반려 사유(고객에게 보임)」에 사유를 적는다. 고객의 주문 상세에 「반려 사유: …」로 그대로 보인다.
2. 「반려」를 누른다. 고객은 같은 상품을 다시 신청할 수 있다.

### 3-3. 교환 승인하고 교환 상품 보내기
1. 「처리 대기」에서 유형 「교환」 신청의 상품 칸을 본다. 「티셔츠 × 1 → 블랙 / L」처럼 받을 옵션이 함께 보인다.
2. 「승인 사유」는 「상품 불량·파손」「오배송」 중에서만 고를 수 있다.
3. 「승인(교환)」 → 「신청 #N을(를) 승인할까요? 교환 옵션 재고를 빼고 회수 상품 재고를 되돌립니다.」에서 확인을 누른다. 교환 옵션 재고가 모자라면 「교환할 옵션의 재고가 부족합니다.」가 뜨고 신청은 「처리 대기」에 남는다.
4. 「교환 발송 대기」 탭으로 옮겨진다. 새 상품을 보낸 뒤 「택배사」「운송장 번호」를 적고 「교환 발송 등록」을 누른다.
5. 「완료」 탭에 「교환 발송 · 택배사 운송장」이 보이고, 고객 화면에도 같은 운송장이 보인다.

## 4. 입력 항목 설명
| 항목 | 필수 | 형식·제한 | 예 |
|---|---|---|---|
| 승인 사유 | 아니요(기본은 고객이 고른 사유) | 단순 변심 / 상품 불량·파손 / 오배송 | 상품 불량·파손 |
| 반려 사유 | 반려할 때 필수 | 1~300자, 고객에게 그대로 보임 | 사용 흔적이 있어 반품할 수 없습니다 |
| 택배사·운송장 번호 | 교환 발송 등록 때 필수 | 각 1~50자 | CJ대한통운 / 123456789012 |

## 5. 상태와 진행 흐름
| 상태(탭) | 뜻 | 다음에 할 일 / 누가 |
|---|---|---|
| 「처리 대기」 | 고객이 반품을 신청했다 | 직원이 승인 또는 반려 |
| 「교환 발송 대기」 | 교환이 승인돼 재고 처리가 끝났다 | 직원이 새 상품을 보내고 운송장을 등록 |
| 「완료」 | 환불이 끝났다(취소는 고객 신청 즉시, 반품은 승인 즉시) 또는 교환 상품을 보냈다 | 없음 |
| 「반려」 | 직원이 반품을 받아들이지 않았다 | 고객이 다시 신청할 수 있다 |

## 6. 자주 보는 메시지와 해결 방법
| 화면 메시지(원문) | 원인 | 해결 |
|---|---|---|
| 「반려 사유를 입력하세요. 고객 화면에 그대로 보입니다.」 | 반려 사유가 비어 있다 | 사유를 적는다 |
| 「반려 사유는 300자 이내로 입력하세요.」 | 사유가 너무 길다 | 줄인다 |
| 「이미 처리된 신청입니다.」 | 다른 직원이 먼저 처리했다 | 탭을 다시 눌러 목록을 새로 고친다 |
| 「택배사와 운송장 번호를 입력하세요.」 | 교환 운송장 칸이 비어 있다 | 둘 다 적는다 |
| 「교환할 옵션의 재고가 부족합니다.」 | 승인하려는 교환 옵션의 재고가 모자란다 | 재고를 채운 뒤 다시 승인하거나, 반려하고 고객에게 반품을 안내한다 |
| 「신청 목록을 불러오지 못했습니다.」 | 주문 서비스에 일시적으로 닿지 못했다 | 잠시 뒤 다시 연다 |

## 7. 알아 둘 제한 사항
- 환불 금액은 주문 서비스가 계산한다: 상품 금액 − 회원 등급 할인 몫 ± 배송비 재계산(단순 변심일 때) − 반품 배송비(단순 변심일 때). 사유를 「상품 불량·파손」「오배송」으로 바꾸면 반품 배송비와 배송비 차감이 빠진다.
- 반품 배송비는 상품 판매 정책의 「반품 배송비(편도)」다. 입력되지 않은 상품은 0원이다.
- 결제는 아직 실제 PG 가 아니다. 「환불」은 주문 서비스의 기록이고 실제 돈이 오가지 않는다.
- 교환 승인은 새 옵션 재고를 먼저 뺀 뒤 확정한다. 확정 전에 오류가 나면 재고만 빠진 채 신청이 「처리 대기」에 남는데, 같은 신청을 다시 승인하면 재고를 두 번 빼지 않고 확정된다.
- 교환으로 받은 상품은 다시 반품·교환할 수 없다(고객 문의로 처리).

## 8. 문의
화면 오류는 개발 담당에게 신청 번호(#N)와 함께 알린다.
