# 회원 등급 정책 관리하고 회원 등급 직접 바꾸기 사용 설명서

| 항목 | 내용 |
|---|---|
| 대상 | 회원 담당 직원(회원 등급 기준·혜택을 정하고, 개별 회원의 등급을 조정하는 사람) |
| 화면 주소 | <https://admin.posselect.com/admin/member-grades> (등급 관리), <https://admin.posselect.com/admin/members> (회원 관리) |
| 필요한 권한 | 관리자 계정 + 「MEMBER_MANAGER」 또는 「SYSTEM_ADMIN」 역할 |
| 최종 확인 | **(미확인) 운영 화면에서는 아직 돌려 보지 못했습니다** — 2026-10-02 작성 시점에 배포 전입니다. 확인한 것은 자동 테스트(등급 추가·수정·삭제 규칙, 같은 요청 반복 시 한 번만 반영, 정기 재산정이 고정된 회원을 유지 기한까지 건너뛰는 것 — auth.api#49)와 화면 빌드까지입니다. 화면 배치, 실제 역할별 접근 차단, 할인율 변경이 주문 금액에 반영되는 것은 배포 후 확인이 필요합니다 |
| 관련 이슈 | lee-dohyun/gateway#80 |

> 양식: [사용자 설명서 표준](https://github.com/lee-dohyun/architecture/blob/main/docs/USER_GUIDE_STANDARD.md)

## 1. 이 기능으로 할 수 있는 일

회원 등급마다 "얼마 이상 사면 이 등급이 되는지(기준액)"와 "몇 % 할인해 주는지(할인율)"를 정합니다.
등급을 새로 만들거나 쓰지 않는 등급을 지울 수 있습니다.
특정 회원의 등급과 변경 이력을 보고, 사유를 적어 등급을 직접 바꿀 수 있습니다.

## 2. 시작하기 전에

- 관리자 계정에 「MEMBER_MANAGER」(또는 「SYSTEM_ADMIN」) 역할이 있어야 상단 메뉴에 「등급 관리」와 「회원 관리」가 보입니다.
  역할이 없으면 메뉴가 보이지 않고, 주소를 직접 입력해도 들어갈 수 없습니다.
- 회원 등급은 **매월 1일 새벽 4시 정기 재산정**에서 자동으로 정해집니다. 최근 6개월 구매확정액(배송완료 기준, 환불·취소 제외)을 등급별 기준액과 비교해, 기준액을 넘긴 등급 중 가장 높은 등급을 줍니다. 구매확정액이 줄면 등급이 내려갑니다.
- 이 화면에서 바꾸는 값이 **언제 적용되는지가 항목마다 다릅니다.** 7번 "알아 둘 제한 사항"을 먼저 읽어 주세요.

## 3. 따라 하기

### 3-1. 등급별 기준액·할인율 보기
1. 상단 메뉴 「등급 관리」를 누릅니다 → 등급 목록이 「순서」, 「코드」, 「이름」, 「할인율」, 「기준액(최근 6개월 구매확정액)」으로 보입니다.
2. 가입할 때 주어지는 등급에는 「기본 등급」 표시가 붙어 있습니다.

### 3-2. 기준액·할인율 고치기
1. 고칠 등급 줄의 「수정」을 누릅니다 → 목록 아래에 「(코드) 등급 수정」 입력 칸이 펼쳐집니다.
2. 「이름」, 「할인율(%)」, 「기준액(원)」, 「정렬 순서」를 고칩니다. 「기본 등급」의 기준액 칸은 잠겨 있습니다(0원 고정).
3. 「저장」을 누릅니다 → 「(코드) 등급을 저장했습니다.」가 보이고 목록에 바뀐 값이 보입니다.

### 3-3. 등급 추가하기
1. 목록 아래 「등급 추가」를 누릅니다 → 「등급 추가」 입력 칸이 펼쳐집니다.
2. 「등급 코드」, 「이름」, 「할인율(%)」, 「기준액(원)」, 「정렬 순서」를 입력합니다. **등급 코드는 만든 뒤에는 바꿀 수 없습니다.**
3. 「저장」을 누릅니다 → 「(코드) 등급을 추가했습니다.」가 보이고 목록에 새 등급이 보입니다.

### 3-4. 등급 삭제하기
1. 지울 등급 줄의 「삭제」를 누릅니다(「기본 등급」에는 「삭제」가 없습니다).
2. 「(이름)((코드)) 등급을 삭제할까요? 되돌릴 수 없습니다.」 확인창에서 확인합니다 → 「(코드) 등급을 삭제했습니다.」
3. 그 등급인 회원이 있거나, 누군가 그 등급이었던 이력이 있으면 삭제되지 않습니다(6번 메시지 참고).

### 3-5. 회원의 등급과 이력 보기
1. 상단 메뉴 「회원 관리」를 누르고, 이메일 또는 이름으로 회원을 찾습니다.
2. 그 회원 줄의 「등급」을 누릅니다 → 「회원 등급」 창이 열리고 현재 등급·할인율과 「등급 이력」이 최신 순으로 보입니다.
3. 직원이 직접 바꾼 이력에는 「수동」 표시가 붙고, 사유가 「수동 조정: (입력한 사유)」로 보입니다.
4. 「로컬 미연동」 표시가 있는 계정(가입이 끝나지 않은 계정)에는 「등급」 버튼이 없습니다 — 등급 자체가 없기 때문입니다.

### 3-6. 회원 등급 직접 바꾸기
1. 3-5처럼 「회원 등급」 창을 엽니다. 현재 등급 아래에 고정 상태(「고정 아님 — 매월 1일 정기 재산정 대상」 또는 「고정됨 — (기한)까지 유지」)가 보입니다.
2. 「바꿀 등급」에서 등급을 고릅니다. 지금 등급도 고를 수 있습니다(「— 현재 등급 유지」 표시) — 구매로 얻은 지금 등급을 고정하거나 유지 기한만 바꿀 때 씁니다.
3. 「유지 기한」을 고릅니다(선택). 비우면 고정을 해제할 때까지 유지됩니다. 오늘 이전 날짜는 고를 수 없습니다.
4. 「조정 사유」를 적습니다(필수, 80자 이하).
5. 「등급 변경」을 누릅니다 → 「(등급 이름) 등급으로 고정했습니다. ((기한)까지 / 해제할 때까지 유지)」가 보이고, 「등급 이력」 맨 위에 「수동」 이력이 한 줄 생깁니다.
6. **이렇게 바꾼 등급은 고정됩니다.** 매월 1일 정기 재산정이 유지 기한까지(비우면 해제할 때까지) 이 회원을 건너뜁니다. 유지 기한이 지나면 그다음 정기 재산정부터 구매확정액 기준으로 다시 계산됩니다.

### 3-7. 등급 고정 해제하기
1. 3-5처럼 「회원 등급」 창을 엽니다. 고정된 회원에게만 「고정 해제」 버튼이 보입니다.
2. 「고정 해제」를 누르고 「등급 고정을 해제할까요? …」 확인창에서 확인합니다 → 「고정을 해제했습니다. 다음 정기 재산정(매월 1일)부터 다시 계산됩니다.」
3. 등급 자체는 그대로 둡니다. 「등급 이력」에 「수동 조정: 고정 해제」 한 줄이 남습니다.

## 4. 입력 항목 설명

| 항목 | 필수 | 설명 | 입력 규칙 |
|---|---|---|---|
| 등급 코드 | 추가할 때 예 | 등급을 구분하는 이름. 만든 뒤 바꿀 수 없음 | 영문 대문자로 시작, 대문자·숫자·밑줄만, 20자 이하 (예: VVIP) |
| 이름 | 예 | 고객과 직원에게 보이는 등급 이름 | 1~50자 |
| 할인율(%) | 예 | 이 등급 회원의 주문에 적용되는 할인율 | 0~100, 소수 둘째 자리까지 |
| 기준액(원) | 아니오 | 최근 6개월 구매확정액이 이 금액 이상이면 이 등급이 됨 | 0 이상. 다른 등급과 같은 금액은 안 됨. 비우면 정기 재산정에서 제외되어 직접 바꿀 때만 부여됨. 「기본 등급」은 0원 고정 |
| 정렬 순서 | 예 | 목록에 보이는 순서(작은 수가 위) | 0 이상의 정수 |
| 바꿀 등급 | 예 | 회원에게 줄 등급 | 지금 등급도 가능(그때는 유지 기한이 지금과 달라야 함) |
| 유지 기한 | 아니오 | 고정이 유효한 마지막 날(그날 포함, 한국 시간) | 오늘 이후 날짜. 비우면 해제할 때까지 고정 |
| 조정 사유 | 예 | 왜 직접 바꾸는지. 등급 이력에 남음 | 80자 이하 |

## 5. 상태와 진행 흐름

해당 없음 — 등급에는 심사·승인 같은 진행 단계가 없습니다. 저장하면 바로 반영됩니다(적용 시점은 7번 참고).

## 6. 자주 보는 메시지와 해결 방법

| 화면 메시지(원문) | 원인 | 해결 |
|---|---|---|
| 권한이 없습니다. MEMBER_MANAGER 또는 SYSTEM_ADMIN 역할이 필요합니다. | 계정에 역할이 없음 | 시스템 관리자에게 역할을 요청 |
| 등급 코드는 영문 대문자로 시작하는 대문자·숫자·밑줄 20자 이하로 입력해 주세요. | 등급 코드 형식이 틀림 | 예: VVIP, VIP_2 |
| 등급 이름은 1~50자로 입력해 주세요. | 이름이 비었거나 너무 김 | 이름을 고쳐 다시 「저장」 |
| 할인율은 0~100 사이 숫자로, 소수 둘째 자리까지 입력해 주세요. | 할인율이 숫자가 아니거나 범위를 벗어남 | 예: 2.5 |
| 기준액은 0 이상의 숫자로 입력해 주세요. | 기준액에 음수·글자를 넣음 | 숫자만 입력(쉼표 없이) |
| 기본 등급의 기준액은 0원이어야 합니다. | 「기본 등급」의 기준액을 0원이 아닌 값으로 저장하려 함 | 0으로 둠 |
| 정렬 순서는 0 이상의 정수로 입력해 주세요. | 정렬 순서가 정수가 아님 | 예: 5 |
| 같은 코드의 등급이 이미 있습니다. | 추가하려는 코드가 이미 쓰이고 있음 | 다른 코드를 쓰거나, 그 등급을 「수정」 |
| 기준액이 같은 다른 등급이 있습니다. 기준액을 다르게 입력해 주세요. | 두 등급의 기준액이 같으면 어느 등급을 줄지 정할 수 없음 | 기준액을 다르게 입력 |
| 기본 등급은 삭제할 수 없습니다. | 가입할 때 주는 등급을 지우려 함 | 지울 수 없음 |
| 이 등급인 회원이 있거나 등급 이력에 남아 있어 삭제할 수 없습니다. | 그 등급을 받은 회원이 있거나 있었음 | 지울 수 없음. 더 주지 않으려면 기준액을 비워 정기 재산정에서 제외 |
| 등급을 찾을 수 없습니다. 화면을 새로고침해 주세요. | 다른 직원이 먼저 그 등급을 지웠음 | 새로고침 |
| 바꿀 등급을 선택해 주세요. | 「바꿀 등급」을 고르지 않음 | 등급을 고름 |
| 조정 사유를 입력해 주세요. | 「조정 사유」가 비어 있음 | 사유를 적음 |
| 조정 사유는 80자 이하로 입력해 주세요. | 사유가 너무 김 | 줄여서 적음 |
| 유지 기한은 오늘 이후 날짜로 선택해 주세요. | 지난 날짜를 고름 | 오늘 이후 날짜를 고르거나 비움(해제할 때까지) |
| 지금 등급·유지 기한과 같습니다. 바꿀 내용이 없습니다. | 이미 같은 등급·같은 기한으로 고정돼 있음 | 바꿀 필요 없음. 기한을 바꾸려면 다른 날짜를 고름 |
| 고정을 해제하지 못했습니다. | 서버 오류 또는 권한 없음 | 잠시 뒤 다시 시도, 계속되면 시스템 관리자에게 문의 |
| 이미 (등급 이름) 등급입니다. 바뀐 것이 없습니다. | 다른 직원이 먼저 같은 등급으로 바꿨거나 같은 요청이 두 번 감 | 그대로 두면 됨. 이력도 한 번만 남음 |
| 등급 정보가 없는 계정입니다(가입이 끝나지 않은 계정). | 가입이 중간에 끊긴 계정 | 등급을 줄 수 없음 |

## 7. 알아 둘 제한 사항

- **직접 바꾼 회원 등급은 고정됩니다** — 정기 재산정이 유지 기한까지(비우면 해제할 때까지) 그 회원을 건너뜁니다. 기한이 지나거나 「고정 해제」를 누르면 그다음 정기 재산정(매월 1일)부터 구매확정액으로 다시 계산됩니다. 예를 들어 구매 이력이 없는 회원을 VIP 로 올리고 기한을 비워 두면 해제할 때까지 VIP 로 유지됩니다.
- 고정 기능이 생기기(2026-10) 전에 직접 바꾼 등급은 고정되지 않은 상태입니다. 그런 회원을 유지하려면 지금 등급을 골라 다시 한 번 조정해 고정하세요.
- **할인율은 저장하는 즉시 적용됩니다** — 그 등급 회원의 다음 주문부터 새 할인율로 계산됩니다. 이미 끝난 주문은 바뀌지 않습니다. 잘못 넣으면 바로 손실이 되므로 저장 전에 숫자를 다시 확인하세요.
- **기준액은 다음 정기 재산정(매월 1일) 때 회원 등급에 반영됩니다** — 저장해도 회원들의 등급이 바로 바뀌지는 않습니다.
- 기준액을 비운 등급은 정기 재산정으로는 누구에게도 주어지지 않습니다. 그 등급을 직접 준 회원은 고정이 유지되는 동안 그 등급에 남고, 고정이 끝나면 다음 재산정에서 구매확정액에 맞는 등급으로 바뀝니다.
- 등급 코드는 만든 뒤 바꿀 수 없습니다 — 주문 기록 등 다른 곳에서 이 코드로 등급을 가리키기 때문입니다.
- 누가 등급을 직접 바꿨는지(직원 계정)는 화면의 이력에 나오지 않습니다. 필요하면 시스템 관리자가 서버 기록에서 확인합니다.
- 등급별 회원 수는 이 화면에 나오지 않습니다.

## 8. 문의

화면 오류나 권한 문제는 시스템 관리자에게 알려 주세요.
