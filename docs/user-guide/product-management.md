> 양식: [사용자 설명서 표준](https://github.com/lee-dohyun/architecture/blob/main/docs/USER_GUIDE_STANDARD.md)
> 파트너가 올린 상품의 심사는 [파트너 상품 검수하기](product-review.md), 파트너가 보는 등록 화면은 lee-dohyun/partner.front `docs/user-guide/product-registration.md`

## 1. 이 기능으로 할 수 있는 일

PosSelect 가 직접 파는 상품(자사 상품)을 등록·수정하고, 배송비·반품 조건 같은 판매 정책을 입력합니다.
상품 목록에서는 파트너가 올린 상품까지 모두 보이며, 판매 중인지·누가 파는지 구분해 볼 수 있습니다.
자사 상품은 검수를 거치지 않고 저장 즉시 반영됩니다.

## 2. 시작하기 전에

- 관리자 계정에 「PRODUCT_MANAGER」(또는 「SYSTEM_ADMIN」) 역할이 있어야 상단 메뉴에 「상품 관리」가 보입니다.
- 상품 사진: JPG·PNG·WEBP, 한 장당 5MB 이하.
- 판매 정책(과세 구분, 배송비, 출고 소요일, 반품·교환 배송비, 반품지)을 정해 두세요. 쇼핑몰 상품 상세에 그대로 공개됩니다.

## 3. 따라 하기

### 3-1. 상품 목록 보기
1. 상단 메뉴 「상품 관리」를 누릅니다 → 모든 상품이 「상태」·「이름」·「판매자」·「가격」·「재고」 열로 보입니다.
2. 위쪽 「전체」·「판매 중」·「미공개」·「판매 중지」·「보관」 버튼으로 걸러 봅니다.
   「미공개」에는 파트너가 작성 중이거나 검수 중인 상품이 들어 있습니다. 쇼핑몰에는 「판매 중」만 보입니다.
3. 목록을 불러오지 못하면 「상품 목록을 불러오지 못했습니다.」가 보입니다. 새로고침해 보세요.

### 3-2. 상품 등록·수정
1. 「상품 추가」를 누르거나, 목록에서 「수정」을 누릅니다.
2. 「카테고리」, 「이름」, 「설명」, 「가격」, 「재고」, 「브랜드」, 「정가」를 입력합니다.
3. 사진은 파일을 골라 올립니다 → 올린 주소가 「이미지 URL (한 줄에 하나씩)」 칸에 추가됩니다. 첫 줄이 대표 사진입니다.
   올리지 못한 파일이 있으면 「일부 이미지를 올리지 못했습니다.」와 함께 파일별 이유가 보입니다.
4. 「저장」을 누릅니다 → 목록으로 돌아갑니다. 실패하면 「저장에 실패했습니다. 입력값을 확인해주세요.」가 보입니다.
5. 옵션(색상·사이즈 등)은 수정 화면 아래 「옵션 & SKU 관리」에서 추가합니다. SKU 가격을 바꾸면 쇼핑몰 가격에도 반영됩니다.

### 3-3. 판매 정책 입력
수정 화면 맨 아래 「판매 정책」에 있습니다. **상품 정보의 「저장」과 따로 저장합니다.**
1. 「과세 구분」, 「배송비」를 고릅니다. 「유료배송」이면 「배송비(원)」, 「조건부 무료배송」이면 「배송비(원)」과 「무료배송 기준 금액(원)」 칸이 나타납니다.
2. 「출고 소요일(영업일)」, 제주·도서산간 추가 배송비, 「반품 배송비(편도, 원)」, 「교환 배송비(왕복, 원)」, 「반품·교환 주소」를 입력합니다.
3. KC 인증 대상이면 「KC 인증」 유형과 「KC 인증번호」를 입력합니다.
4. 필요하면 「판매 시작 (비우면 제한 없음)」, 「판매 종료 (비우면 제한 없음)」, 「1회 최대 구매 수량」을 입력합니다.
5. 「판매 정책 저장」을 누릅니다 → 「판매 정책을 저장했습니다.」
   → 쇼핑몰 상품 상세에 「배송·교환·반품 안내」가 나타납니다. 판매 기간 밖이거나 최대 수량을 넘으면 고객의 장바구니 담기·주문이 막힙니다(상품은 목록에 계속 보입니다).
   판매 정책을 한 번도 저장하지 않은 상품은 쇼핑몰에 「배송·교환·반품 안내」가 나오지 않습니다.

## 4. 입력 항목 설명

| 항목 | 필수 | 설명 | 입력 규칙 |
|---|---|---|---|
| 카테고리 / 이름 / 가격 / 재고 | 예 | | 가격·재고 0 이상 |
| 설명 / 브랜드 | 아니오 | | |
| 정가 | 아니오 | 할인 전 가격 | 판매가보다 낮으면 할인율이 음수로 보입니다 |
| 배송 배지 | 아니오 | 목록에 붙는 배송 표시 | 「없음」 또는 「최적 배송」. 표시용이라 실제 출고일과 연결되지 않습니다 |
| 사진 | 아니오 | 첫 줄이 대표 사진 | JPG·PNG·WEBP, 장당 5MB 이하 |
| 과세 구분 | 아니오(권장) | 과세·면세·영세 | |
| 배송비 | 아니오(권장) | 무료배송 / 조건부 무료배송 / 유료배송 | 유료면 배송비, 조건부면 배송비와 기준 금액 필수 |
| 출고 소요일(영업일) | 아니오 | 결제 후 출고까지 | 0 이상 정수 |
| 제주·도서산간 추가 배송비 / 반품·교환 배송비 | 아니오 | | 0 이상 |
| 반품·교환 주소 | 아니오(권장) | | 300자 이하 |
| KC 인증 / 인증번호 | 해당 상품만 | | 「인증 대상 아님」이 아니면 번호 필수 |
| 판매 시작·종료 | 아니오 | | 종료가 시작보다 뒤 |
| 1회 최대 구매 수량 | 아니오 | 한 번에 살 수 있는 수량(옵션 합계 기준) | 1 이상 정수 |

평점·리뷰 수는 더 이상 이 화면에서 입력하지 않습니다(직접 입력한 평점은 허위 표시가 될 수 있어서). 이미 있는 값은 저장해도 그대로 유지됩니다.

## 5. 상태와 진행 흐름

| 상태(화면 표시) | 뜻 | 다음에 할 일 / 누가 |
|---|---|---|
| 판매 중 | 쇼핑몰에 노출·판매 | — |
| 미공개 | 파트너가 작성 중이거나 검수 중 | 파트너 제출 → 「상품 검수」에서 심사 |
| 판매 중지 / 보관 | 노출되지 않음 | — |

자사 상품은 등록 즉시 「판매 중」입니다(검수 없음).

## 6. 자주 보는 메시지와 해결 방법

| 화면 메시지(원문) | 원인 | 해결 |
|---|---|---|
| 상품 목록을 불러오지 못했습니다. | 서버 응답 실패 | 새로고침. 계속되면 시스템 관리자에게 |
| JPG, PNG, WEBP 이미지만 올릴 수 있습니다. | 다른 형식(확장자만 바꾼 파일 포함) | JPG·PNG·WEBP 로 다시 저장해서 올리기 |
| 이미지는 5MB 이하만 올릴 수 있습니다. | 파일이 큼 | 크기를 줄여서 올리기 |
| 저장에 실패했습니다. 입력값을 확인해주세요. | 필수 항목 누락·형식 오류 | 입력값 확인 |
| 유료배송은 배송비를 입력해야 합니다. / 조건부 무료배송은 배송비와 무료배송 기준 금액을 입력해야 합니다. / KC 인증 대상이면 인증번호를 입력해야 합니다. / 판매 종료 시각은 시작 시각보다 뒤여야 합니다. | 판매 정책 입력이 서로 맞지 않음 | 안내대로 고친 뒤 「판매 정책 저장」 |
| 판매 정책 저장에 실패했습니다. | 권한 없음 또는 서버 오류 | 역할 확인. 계속되면 시스템 관리자에게 |

## 7. 알아 둘 제한 사항

- 무료배송 표시는 판매 정책의 「배송비」에서 정해집니다. 상품 정보 화면에는 현재 값만 보이고 직접 바꿀 수 없습니다. 판매 정책이 없는 상품은 기존 값이 그대로 유지됩니다.
- 옵션을 만든 상품은 상품 정보의 「가격」·「재고」를 바꿀 수 없습니다. 「옵션 & SKU 관리」에서 조합별로 고칩니다.
- 판매 기간 밖이거나 최대 수량을 넘는 구매는 막히지만, 상품은 쇼핑몰 목록·상세에 계속 보입니다.
