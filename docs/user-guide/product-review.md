| 화면 주소 | <https://admin.posselect.com/admin/submissions> |
| 필요한 권한 | 관리자 계정 + 「PRODUCT_MANAGER」 또는 「SYSTEM_ADMIN」 역할 |

## 1. 이 기능으로 할 수 있는 일

판매 파트너가 파트너센터에서 제출한 상품 중 **자동 검사를 통과한 것**을 사람이 최종 심사합니다.
승인하면 상품이 바로 쇼핑몰에 판매 상품으로 노출되고, 보완 요청을 보내면 파트너 화면에 사유가 그대로 표시됩니다.

## 2. 시작하기 전에

- 관리자 계정에 「PRODUCT_MANAGER」(또는 「SYSTEM_ADMIN」) 역할이 있어야 상단 메뉴에 「상품 검수」가 보입니다.
  역할이 없으면 메뉴가 보이지 않고, 주소를 직접 입력해도 들어갈 수 없습니다.
- 자동 검사가 이미 끝난 뒤 넘어오므로, 필수 입력 누락·금지 표현·가격 오류 같은 **기계적 확인은 끝난 상태**입니다.
  사람은 **사진·설명이 실제 상품과 맞는지, 고시 내용이 그럴듯한지, 판매해도 되는 상품인지**를 봅니다.

## 3. 따라 하기

### 3-1. 심사할 상품 찾기
1. 상단 메뉴 「상품 검수」를 누릅니다 → 「심사 대기」 목록이 기본으로 보입니다.
2. 다른 상태를 보려면 「보완 요청」, 「승인」, 「전체」 버튼을 누릅니다.
3. 목록에서 상품 이름을 누르면 상세 화면으로 갑니다.

### 3-2. 내용 확인하기
상세 화면은 위에서부터 이렇게 보입니다.
1. **제목 줄**: 제출 번호, 상품명, 상태. 그 아래 판매자·제출자·최근 변경 시각.
2. **「자동 검사 결과」**: 「차단 · …」(빨간색)은 통과 못 한 항목, 「경고 · …」은 통과는 됐지만 봐야 할 항목입니다.
   심사 대기 상태라면 보통 차단 항목은 없고 경고만 있을 수 있습니다.
3. **「상품 정보」**: 사진, 카테고리, 상품명, 브랜드, 판매가/정가, 재고, 무료배송 여부, 상세 설명.
4. **「상품정보제공고시」**: 카테고리가 요구하는 항목과 파트너가 입력한 값. 필수인데 비어 있으면 「(비어 있음)」이 빨간색으로 보입니다.
   판매 권한이 필요한 카테고리면 필요 서류 이름도 표시됩니다.

### 3-3. 승인하기
1. (선택) 「사유 / 메모」에 남길 말을 적습니다.
2. 「승인」을 누릅니다 → 「승인하면 이 상품이 즉시 쇼핑몰에 노출됩니다. 승인할까요?」 확인창에서 확인합니다.
3. 「승인했습니다. 상품이 판매 중으로 바뀌었습니다.」가 보이면 끝입니다. 상태가 「승인」으로 바뀝니다.

### 3-4. 보완 요청하기
1. 「사유 / 메모」에 **파트너가 무엇을 고쳐야 하는지** 적습니다. **필수**이며 500자 이하입니다.
   이 문장이 파트너 화면 맨 위에 「심사 의견: …」으로 그대로 보이므로, 파트너가 읽고 바로 고칠 수 있게 구체적으로 씁니다.
   (좋은 예: 「전성분에 알레르기 유발 성분 표기를 추가해 주세요.」 / 나쁜 예: 「내용 보완 필요」)
2. 「보완 요청」을 누릅니다 → 「보완 요청을 보냈습니다.」가 보이고 상태가 「보완 요청」으로 바뀝니다.
3. 파트너가 고쳐서 다시 제출하면 자동 검사를 거쳐 다시 「심사 대기」 목록에 올라옵니다.

## 4. 입력 항목 설명

| 항목 | 필수 | 설명 | 입력 규칙 |
|---|---|---|---|
| 사유 / 메모 | 보완 요청 시 예, 승인 시 아니오 | 파트너에게 보이는 심사 의견 | 500자 이하. 앞뒤 공백은 지워집니다 |

## 5. 상태와 진행 흐름

| 상태(화면 표시) | 뜻 | 다음에 할 일 / 누가 |
|---|---|---|
| 제출됨 · 자동 검사 중 | 파트너가 방금 제출, 자동 검사 진행 중 | 기다리기(보통 몇 초) |
| 보완 요청 | 자동 검사에서 걸렸거나 심사자가 보완 요청 | 파트너가 고쳐서 재제출 |
| 심사 대기 | 자동 검사 통과, 사람 심사 필요 | **직원: 승인 또는 보완 요청** |
| 승인 | 판매 시작(쇼핑몰 노출) | — |

승인·보완 요청 버튼은 **「심사 대기」일 때만** 나타납니다. 다른 상태에서는
「이 제출은 지금 심사할 수 있는 상태가 아닙니다 (심사 대기일 때만 승인·보완 요청 가능).」가 보입니다.

## 6. 자주 보는 메시지와 해결 방법

| 화면 메시지(원문) | 원인 | 해결 |
|---|---|---|
| 보완 요청 사유를 입력해 주세요. 파트너는 이 문장을 보고 수정합니다. | 사유 없이 「보완 요청」 | 사유를 적고 다시 누르기 |
| 차단 항목이 남아 있어 승인할 수 없습니다. | 자동 검사 차단 항목이 있음(「승인」 버튼이 꺼짐) | 「보완 요청」으로 돌려보내기 |
| 허용되지 않는 전이: … | 그사이 다른 사람이 먼저 처리했거나 파트너가 상태를 바꿈 | 새로고침해서 현재 상태 확인 |
| 해당 상태의 제출이 없습니다. | 그 필터에 해당하는 건이 없음 | 정상 |
| 제출을 찾을 수 없습니다. | 없는 제출 번호로 접속 | 목록에서 다시 들어가기 |
| Forbidden - Access Denied | 계정에 「PRODUCT_MANAGER」/「SYSTEM_ADMIN」 역할이 없음 | 관리자에게 역할 요청 |

## 7. 알아 둘 제한 사항

- **승인은 되돌리는 화면이 없습니다.** 승인 즉시 쇼핑몰에 노출되므로 확인창에서 한 번 더 확인하세요.
  판매를 멈춰야 하면 개발 담당에게 요청해야 합니다(판매 중지 화면 미구현).
- 「상품 관리」 목록에는 아직 **판매자와 상태 열이 없어** 파트너가 작성 중인 상품과 판매 중인 상품이 섞여 보입니다
  (lee-dohyun/admin.front#50 에서 추가 예정). 검수는 이 「상품 검수」 화면에서 하세요.
- 판매 권한이 필요한 카테고리의 **서류 확인·권한 부여 화면은 아직 없습니다.**
- 「허용되지 않는 전이」처럼 개발 용어가 그대로 보이는 메시지가 남아 있습니다.
