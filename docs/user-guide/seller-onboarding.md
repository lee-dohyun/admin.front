## 1. 이 기능으로 할 수 있는 일

판매 파트너(외부 업체)를 등록하고, 입점 심사를 거쳐 승인하거나 반려합니다.
승인한 업체에는 파트너센터(partner.posselect.com) 로그인 계정을 발급합니다.
판매 중인 업체를 정지하거나 계약을 해지하는 것도 여기서 합니다.

## 2. 시작하기 전에

- 관리자 계정에 「PARTNER」(또는 「SYSTEM_ADMIN」) 역할이 있어야 상단 메뉴에 「판매자 관리」가 보입니다.
  역할이 없으면 메뉴가 보이지 않고, 주소를 직접 입력해도 들어갈 수 없습니다.
  (여기서 「PARTNER」는 **직원의 역할 이름**입니다. 외부 파트너 계정과는 다릅니다.)
- 파트너가 스스로 가입하는 화면은 없습니다. 입점 신청을 받으면 **담당 직원이 대신 등록**합니다.
- 업체의 사업자등록증, 통신판매업 신고증을 받아 두세요. 화면에 입력하는 정보는 등록증과 같아야 합니다.

## 3. 따라 하기

### 3-1. 새 판매자 등록하기
1. 상단 메뉴 「판매자 관리」를 누릅니다 → 「심사 요청」 목록이 기본으로 보입니다.
2. 「신규 판매자 등록」을 누릅니다 → 입력 칸이 펼쳐집니다.
3. 상호, 사업자등록번호, 대표자, 사업장 주소, 전화번호, 이메일을 입력합니다. 통신판매업 신고번호는 있으면 입력합니다.
   **이메일은 나중에 파트너센터 로그인 아이디가 됩니다.**
4. 「등록」을 누릅니다 → 새 판매자의 상세 화면으로 이동하고, 상태가 「작성 중」으로 보입니다.

### 3-2. 심사하기
상세 화면 맨 위 「심사」에서 지금 상태에 맞는 버튼만 보입니다.
1. 「작성 중」 → 「심사 요청」을 누릅니다 → 확인창에서 확인 → 「심사 요청(으)로 바꿨습니다.」
2. 「심사 요청」 → 「심사 시작」을 누릅니다 → 상태가 「심사 중」으로 바뀝니다.
3. 아래 「기본 정보 · 판매 설정」과 「제출 서류」를 사업자등록증과 대조합니다.
4. 문제가 없으면 「승인」 → 상태가 「운영 중」으로 바뀝니다. 이제 파트너 계정을 발급할 수 있습니다(3-3).
5. 문제가 있으면 「사유」에서 반려 사유를 고르고(필요하면 「보충 설명」도 적고) 「반려」를 누릅니다.
   사유를 고르면 「판매자에게 전달될 문구: …」가 바로 아래에 보이니 내용을 확인하세요.
   → 상태가 「반려」로 바뀝니다. 업체가 보완하면 「보완 후 재심사 요청」을 눌러 다시 심사합니다.

### 3-3. 파트너 계정 발급하기
1. 상태가 「운영 중」인 판매자의 상세 화면에서 「파트너 계정」의 「파트너 계정 발급」을 누릅니다.
2. 「(이메일) 로 파트너 계정을 발급할까요? 초기 비밀번호는 이 화면에서 한 번만 보입니다.」 확인창에서 확인합니다.
3. 아이디와 초기 비밀번호가 표시됩니다. **이 비밀번호는 다시 볼 수 없습니다.**
   화면에도 「이 비밀번호는 다시 볼 수 없습니다. 판매자에게 안전한 경로로 전달하세요.」라고 나옵니다.
   비밀번호를 판매자에게 안전하게 전달하세요. 메신저 단체방이나 공개 게시판은 쓰지 마세요.
4. 판매자는 partner.posselect.com 에서 이 아이디와 비밀번호로 로그인합니다.

### 3-4. 비밀번호를 잃어버렸을 때
1. 판매자 상세 화면 「파트너 계정」에서 「비밀번호 재발급」을 누릅니다.
2. 「비밀번호를 새로 발급할까요? 기존 비밀번호로는 더 이상 로그인할 수 없습니다.」에서 확인합니다.
3. 새 비밀번호가 한 번 표시됩니다. 3-3의 3번처럼 전달합니다.

### 3-5. 판매 정지·해지하기
1. 「운영 중」 판매자에서 사유를 고르고 「판매 정지」 → 상태 「정지」. 이때부터 그 업체는 파트너센터에서 상품을 새로 등록하거나 고칠 수 없습니다(조회는 됩니다). 그 업체의 판매 중 상품은 쇼핑몰에 **그대로 보이지만 「판매 중단」으로 표시되고 장바구니 담기·주문이 막힙니다.** 「정지 해제」하면 바로 다시 팔립니다.
2. 「정지」 상태에서 「정지 해제」를 누르면 다시 「운영 중」, 사유를 고르고 「계약 해지」를 누르면 「해지」가 됩니다. **해지는 되돌릴 수 없습니다.**

### 3-6. 판매자 정보·판매 설정 고치기
1. 상세 화면 「기본 정보 · 판매 설정」에서 값을 고치고 「저장」 → 「판매자 정보를 저장했습니다.」
2. 정산 은행·계좌, 출고지, 반품·교환지, 배송비 정책(메모), CS 연락처도 여기서 입력합니다.

## 5. 상태와 진행 흐름

| 상태(화면 표시) | 뜻 | 다음에 할 일 / 누가 |
|---|---|---|
| 작성 중 | 등록만 된 상태 | 담당 직원: 「심사 요청」 |
| 심사 요청 | 심사 대기 | 담당 직원: 「심사 시작」 |
| 심사 중 | 서류·정보 확인 중 | 담당 직원: 「승인」 또는 「반려」 |
| 운영 중 | 판매 가능. 파트너 계정 발급 가능 | 담당 직원: 계정 발급. 필요하면 「판매 정지」 |
| 반려 | 서류·정보 문제로 돌려보냄 | 업체 보완 후 담당 직원: 「보완 후 재심사 요청」 |
| 정지 | 파트너센터에서 상품 등록·수정 불가(조회만). 판매 중 상품은 보이지만 「판매 중단」(담기·주문 불가) | 담당 직원: 「정지 해제」 또는 「계약 해지」 |
| 해지 | 계약 종료. 판매 중 상품은 정지와 같이 「판매 중단」 | 되돌릴 수 없음. 상품을 쇼핑몰에서 내리려면 상품 관리에서 상태를 바꿈 |

## 6. 자주 보는 메시지와 해결 방법

| 화면 메시지(원문) | 원인 | 해결 |
|---|---|---|
| 필수 항목(상호·사업자등록번호·대표자·주소·전화·이메일)을 모두 입력해 주세요. | 신규 등록에서 필수 칸이 비었음 | 빈 칸을 채우고 다시 「등록」 |
| 사유를 먼저 선택해 주세요. | 반려·정지·해지 버튼을 사유 없이 누름 | 「사유」를 고른 뒤 다시 누름 |
| 지금 상태(…)에서는 …(으)로 바꿀 수 없습니다. 화면을 새로고침해 주세요. | 다른 직원이 먼저 상태를 바꿨음 | 새로고침한 뒤 지금 상태에 맞는 버튼을 누름 |
| 운영 중(승인된) 판매자에게만 계정을 발급할 수 있습니다. | 승인 전에 계정 발급을 시도함 | 먼저 「승인」 |
| 이 판매자에게는 이미 파트너 계정이 발급되어 있습니다. | 계정이 이미 있음 | 비밀번호를 잃었으면 「비밀번호 재발급」 |
| 같은 아이디(…)의 파트너 계정이 이미 있습니다. 판매자 이메일을 확인해 주세요. | 다른 판매자가 같은 이메일로 계정을 받았음 | 판매자 이메일을 확인·수정한 뒤 다시 발급 |

## 7. 알아 둘 제한 사항

- 초기 비밀번호는 발급 화면에서 **한 번만** 보입니다 — 저장해 두지 않기 때문입니다(유출 방지). 놓쳤으면 「비밀번호 재발급」.
- 파트너가 자기 비밀번호를 스스로 바꾸는 화면은 아직 없습니다. 바꾸려면 담당 직원이 재발급합니다.
- 「제출 서류」에 파일을 올리는 화면은 아직 없습니다. 서류는 다른 경로로 받아 대조합니다.
- 판매자 이메일을 바꿔도 이미 발급한 로그인 아이디는 바뀌지 않습니다.
- 판매자를 정지·해지해도 상품이 쇼핑몰에서 내려가지는 않습니다. 「판매 중단」으로 보이고 살 수만 없습니다(2026-09-30 결정, lee-dohyun/product.api#100). 이미 장바구니에 담긴 것은 주문 단계에서 막힙니다.
